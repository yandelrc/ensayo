ENSAYO WEB BILINGÜE — EL PODER DE LOS PEQUEÑOS HÁBITOS

Archivos:
- index.html: versión en español
- english.html: versión en inglés
- style.css: estilos compartidos
- script.js: interactividad (modo oscuro, botón de reflexión y navegación)

Cómo abrir:
1. Extrae el ZIP.
2. Abre index.html en Chrome, Edge o Firefox.
3. Para inglés, abre english.html o usa el selector Español / English.

Nota: las fuentes de Google Fonts necesitan internet; si no hay conexión, se usarán fuentes de respaldo.
